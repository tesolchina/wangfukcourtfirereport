# 調查問了規則，卻從未問制訂規則的人

獨立委員會已於十月二十二日向行政長官提交報告，紅刪版最快下周公布。一百六十八條人命，公眾等待的是一個答案：誰要負責。

但這份報告能回答的，恐怕只是問題的一半。

委員會的工作量毋庸置疑：三十場公開聆訊、八十二人次證人、二百四十三份文件，卷宗數千頁。問題在於，這些證據是從誰口中取得的。

我們把三十一場聆訊的逐字紀錄轉為機器可讀文本，逐條編碼提問的性質。以四月二十七日為例，全日二百八十五條提問，八成二屬於「執行」層面——問的是當日發生什麼、程序有否跟隨、某條例如何套用於某個案。屬於「政策制定」層面的，只有十七條，約百分之六。

這百分之六並非不存在。委員會確實問過：為何設立註冊檢驗人員、為何強制驗樓計劃以風險為本、為何窗戶要有自然採光、為何串謀的刑罰只此水平。問題是，這些問題全部問了執行規則的人——屋宇署助理署長、退休測量師、民政事務總署聯絡主任——而不是制訂規則的人。

答案因此也是執行者的答案：部門的理解、部門的慣例、部門的解釋。至於當初為何這樣規定、有沒有考慮其他方案、為何標準定在這個水平，紀錄裡沒有。

以圍網為例。火災之後，公眾最常問的是：為何棚網的阻燃要求只是指引，而非強制標準？這是一條政策問題，答案在制訂標準的局。但在聆訊裡，這個問題被拆解成執行問題——屋宇署如何巡查、如何通知、如何抽樣、如何跟進。每一條都問得仔細，卻沒有一條問到：當初是誰決定它只是指引。

同樣的翻譯發生在另外兩條問題上。三億三千萬元的維修如何招標、為何圍標難以察覺——這些關乎採購制度與監管設計，屬政策範疇；但聆訊裡的提問，集中在誰收了錢、誰簽了文件、誰沒有申報。至於制度為何容許這樣運作，留白。

傳媒的關注點也值得對照。火災後十日，報道反覆追問的正是這幾件事。公眾問的是規則，紀錄答的是執行。

證人名單本身就是證據。八十二人次之中，二十四是居民，十七人來自承建商，十五人是消防處人員，五位專家；其餘來自屋宇署、勞工處、民政事務總署、市區重建局、警務處和獨立審查組。局長、常任秘書長、副局長，一個也沒有。

委員會的結案陳詞也留下同樣的痕跡。處理政府部門責任的一章長達一百一十頁，通篇沒有出現「局」字，責任落在獨立審查組、屋宇署、消防處和勞工處。但獨立審查組本身是房屋局屬下單位，向房屋局常任秘書長負責；它的授權範圍、它沿用的標準，都不是它自己決定的。

這不是說委員會沒有提出政策建議。它建議修例，建議把罰則提高至五十萬元及監禁十二個月。但建議背後的證據來自執行者，而非制訂者。由「什麼出了問題」推論到「規則應該怎樣改」，中間那一步，是靠推斷完成的。

政策制定與政策執行是兩個層次。只查執行，等於只問「有沒有做」，不問「為什麼這樣規定」。對於一場涉及系統性失效的火災，這樣的調查並不完整。

還有一層。政府正大力推動人工智能與數碼治理，但委員會的二百四十三份文件，至今仍以掃描影像和零散檔案的形式發布，公眾難以搜尋，機器無法閱讀。連最基本的機器可讀格式都沒有，所謂智慧城市，只是口號。資訊公開不只是「放了上網」，而是公眾找得到、用得上。

我們因此要求：行政長官在決定誰要負責的同時，要求政策局回答——每一條規則當初為何這樣定，今天為何仍然這樣定。委員會已完成工作，但公眾有權知道，那些從未被傳召的人，究竟決定了什麼。

*方法說明：三十一場英文聆訊逐字紀錄經規則化抽取（分場、證人、提問與答覆配對）後，由語言模型按「執行／制定／程序」三類逐條編碼，並以人手覆核樣本；四月二十七日樣本的人手與模型一致率約八成八。完整數據與方法見 wangfukcourtfirereport.simonsays.hk。*
